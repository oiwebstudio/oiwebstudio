Esta página está en _borradores/, fuera del sitemap y bloqueada en robots.txt. Sirve para dos cosas: ver cómo quedan los dos componentes que faltan, y tener el HTML listo para pegar en cuanto tengas el contenido.

Todo lo resaltado en amarillo es un hueco por rellenar. No hay ni un testimonio de ejemplo con nombre realista a propósito: si esto se colara en producción, no engañaría a nadie.

Cómo se rellena cada tarjeta

.testi__ini → la inicial del negocio (evita pedir una foto que quizá no exista).
.testi__negocio → nombre real del negocio. .testi__donde → localidad.
.testi__ver → enlace a su web publicada. Esto es lo que hace el testimonio comprobable, que es la diferencia entre prueba social y decoración. Si el cliente no quiere que se enlace, se quita el <a> entero.

3 · Marcado de reseñas para Google (cuando haya testimonios reales)

Este JSON-LD hace que Google pueda entender las reseñas. Solo se activa con testimonios reales y verificables: marcar reseñas inventadas incumple las directrices de Google y puede penalizar el dominio entero. Se pega en el <head> de index.html, con un bloque por testimonio.

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "ProfessionalService",
  "name": "OI Studio",
  "url": "https://oiwebstudio.com/",
  "review": [
    {
      "@type": "Review",
      "author": { "@type": "Organization", "name": "NOMBRE DEL NEGOCIO" },
      "reviewBody": "FRASE DEL CLIENTE",
      "reviewRating": { "@type": "Rating", "ratingValue": "5", "bestRating": "5" }
    }
  ]
}
</script>
